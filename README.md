# 🎅 สมุดรายรับรายจ่าย (LINE + เว็บ) · ธีมคริสต์มาส

พิมพ์รายรับรายจ่ายในแชท LINE บอทแยกรายการ จัดหมวด และจำคำของแต่ละคนให้เอง ดูสรุปสวยๆ ในเว็บ ใช้ฟรีทั้งหมด

ดูหน้าเว็บแบบทดลอง (ไม่ต้องล็อกอิน): `https://<เว็บของคุณ>/?demo=1`

## 🎁 เอฟเฟกต์ & ลูกเล่น (หน้าเว็บ)
- การ์ดยอดเงินเอียง 2.5D + แสงวิ้ง · ตัวเลขนับขึ้นแล้วเด้ง · การ์ดยอดย่อ/จางตอนเลื่อน · เมนูล่างก้อนกระจกเลื่อนแบบสปริง · แตะหมวดแล้ววิ้ง
- บันทึก = รถเลื่อนซานต้าพุ่งทะยาน + หิมะ/ดาวทอง (`sleighFx()`) · ลบ = ละอองหิมะกระจาย (`starBurst()`) + ไอคอนม้วนลงถัง · ฉลองครั้งเดียวเมื่อจดติดกันครบ 3 / 7 / 14 / 30 / 60 / 100 วัน
- **โหมดคู่รัก (ปุ่ม `💑 คู่รัก`):** รูปโปรไฟล์เรากับแฟนใหญ่กลางจอ หัวใจเต้น/ลอย วงแสงหมุน แตะแล้วหัวใจระเบิด ลากได้
- **ลื่นทันที:** บันทึก/แก้/ลบ ตัวเลขเปลี่ยนบนจอทันที แล้วส่งเซิร์ฟเวอร์เบื้องหลัง (ไม่สำเร็จ → คืนค่าเดิม + แจ้ง) · เปิดเว็บแล้วโชว์ข้อมูลที่จำในเครื่องทันที · โหลดเดือนก่อน/ถัดไปไว้ล่วงหน้า
- **เมนูล่างแบบ iPhone:** แคปซูลกระจก กดค้างแล้วลากนิ้วไปมาได้ ปล่อยตรงไหนไปหน้านั้น ปล่อยบน ➕ = เพิ่มรายการ
- **สะบัดนิ้วไม่ค้าง:** ไม่สลับคลาสตอนไถ · คำนวณการ์ดเอียงด้วย `requestAnimationFrame` หยุดเมื่อ `scrollY > 220` · ไม่มี `backdrop-filter` บนการ์ดที่ขยับ · แถวรายการ `contain: layout style paint`
- **หยุดแอนิเมชันฉากหลังชั่วคราว** เมื่อเปิดหน้าต่าง (`body.sheet-open`) · สลับไปแอปอื่น (`body.bg-hidden`) แล้วเล่นต่อเอง
- **กันพัง:** ฟังก์ชันเอฟเฟกต์ทุกตัวห่อด้วย `fx()` (try/catch) → เอฟเฟกต์พลาด การจด/แก้/ลบ/ซิงก์ไม่ค้าง
- **กำลังรีบ** (บันทึกติดกันใน 5 วิ, `RUSH_MS`) → ข้ามแอนิเมชันบันทึก · ประกายตอนบันทึกโผล่ ~1 ใน 10 ครั้ง (`FUN_CHANCE`) · ทดสอบให้โผล่ทุกครั้ง: เติม `&fun=1`
- ปิดลูกเล่นทั้งหมด: ปุ่ม 🎅 มุมขวาบน หรือ ตั้งค่า → หน้าตา → ลูกเล่นคริสต์มาส · เครื่องที่ตั้ง "ลดการเคลื่อนไหว" จะนิ่งเอง

- Firestore Rules ต้องปิดการเข้าถึงจากภายนอกทั้งหมด (`allow read, write: if false;`) เพราะระบบเข้าผ่านเซิร์ฟเวอร์เท่านั้น

## ⚙️ ติดตั้งครั้งแรก (ทำครั้งเดียว)

1. **Firebase**: สร้าง Firestore (ที่ตั้ง `asia-southeast1`) → Project settings → Service accounts → Generate new private key
2. **LINE Messaging API**: เอา Channel secret + Channel access token
3. **LINE Login + LIFF**: สร้าง LIFF (Size: Full, Endpoint: `https://<เว็บ>.vercel.app/`, Scopes: openid + profile) แล้วตั้ง channel เป็น **Published**
4. **Vercel → Environment Variables** ใส่ 5 ตัว แล้ว **Redeploy**
