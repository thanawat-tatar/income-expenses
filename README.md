# 🎀 สมุดรายรับรายจ่าย (LINE + เว็บ)

พิมพ์รายรับรายจ่ายในแชท LINE บอทแยกรายการ จัดหมวด และจำคำของแต่ละคนให้เอง ดูสรุปสวยๆ ในเว็บ ใช้ฟรีทั้งหมด

ดูหน้าเว็บแบบทดลอง (ไม่ต้องล็อกอิน): `https://<เว็บของคุณ>/?demo=1`

## 🧠 บอทเรียนรู้ยังไง
- คำที่ไม่รู้จัก บอทถามในแชท มีปุ่มให้เลือกหมวด → จำไว้ใน**บัญชีของคนนั้นคนเดียว**
- พิมพ์สอนเองได้: `แซนวิช = ค่ากิน` · `หมวดใหม่ ค่าขนมลูก` · `ลบคำ แซนวิช`
- คำและหมวดของแต่ละคนเก็บแยกที่ `users/{LINE userId}` ไม่ปนกัน

## ✏️ แก้ไข / ลบ ในแชท
- พิมพ์ `แก้ไข` · `พิมพ์ผิด` · `ขอแก้ราคาได้ไหม` · `ยอดผิด` → ขึ้นรายการ**วันนี้** (ว่าง → เมื่อวาน) ทีละ 10 + ปุ่ม 📅 เมื่อวาน / 🗓️ เลือกวัน
- `ยกเลิกเมื่อกี้` · `ลบอันล่าสุด` · `จดซ้ำ` → ถามว่าจะลบชุดล่าสุดไหม (คำทั้งหมดอยู่ใน `lib/intents.js` + ทดสอบใน `tests/intents.test.mjs`)
- บอกเจาะจงได้: `แก้ค่ากินวันที่12` · `แก้รายการเมื่อวาน` · `ลบ ข้าว 50` · `แก้ข้าว 50 เป็น 60`
- บอทไม่เข้าใจ 2 ครั้งติดกัน → ส่งปุ่มเปิดหน้าตั้งค่าในเว็บให้

## 🗄️ ข้อมูลเก่า
- เก็บรายละเอียดเดือนนี้ + เดือนก่อน เก่ากว่านั้นรวมเป็นยอดรายเดือนตามหมวด (ทำเองเดือนละครั้งตอนเปิดเว็บ) ดูรายเดือน/รายปีได้ตามปกติ

## 🚪 ด่านรับคน + ข้อมูลส่วนตัว (PDPA)
- รับได้ **20 คน** (ปรับได้ในหน้าหลังบ้าน) เต็มแล้วคนใหม่ได้การ์ด "เต็มแล้ว" + ปุ่ม **ลงชื่อรอคิว**
- มีที่ว่าง → รับคิวแรกเข้าทันที และ**บอททักไปบอก 1 ครั้ง** (push คนละครั้ง ใช้โควต้าข้อความฟรีของ OA) พร้อมการ์ดยอมรับ
- ได้ที่แล้วไม่กดยอมรับใน **3 วัน** → ยกที่ให้คิวถัดไป · กด "ไม่ยอมรับ" → ส่งต่อคิวถัดไปทันที
- คนใหม่ต้องกด **💖 ยอมรับทั้งหมด** ก่อนบันทึก (การ์ดสรุป 9 ข้อ) · ฉบับเต็ม 13 หัวข้อแบบแตะอ่าน: `/privacy.html`
- พิมพ์ `ลบข้อมูลของฉัน` → ถาม 2 ขั้น → ลบทุกอย่างของคนนั้น
- หายไป **14 วัน** กลับมาบอทเตือน · ไม่ใช้ **30 วัน** ลบอัตโนมัติ (Vercel Cron ตี 3 ทุกวัน `api/cron.js`)
- ข้อมูล: `meta/stats` (count, limit) · `waitlist/{uid}` · `users/{uid}`: `joinedAt` `lastActive` `consentAt` `consentVersion` `pendingSince` `invitedAt`
- แก้นโยบายเรื่องสำคัญ → เพิ่ม `POLICY_VERSION` ใน `lib/access.js` และแก้ `public/privacy.html`

## 💑 โหมดคู่รัก (เลือกใช้เอง · แชท + เว็บ)
คนที่ไม่จับคู่ จะไม่เห็นอะไรเปลี่ยนเลย

| พิมพ์ / แตะ | บอททำ |
|---|---|
| `จับคู่` | การ์ดจดหมายเชิญ → แตะ **💌 สร้างรหัสเชิญ** → ได้รหัส 8 ตัว (10 นาที ใช้ครั้งเดียว) + ปุ่ม **📤 ส่งให้แฟน** |
| แฟนแตะลิงก์ → กดส่ง `จับคู่ K7QM-2PXH` | เห็นชื่อ+รูปคนเชิญ → แตะ **💑 ยืนยัน** = จับคู่เสร็จทันที |
| (คนเชิญได้ข้อความ) | "💑 จับคู่สำเร็จ" พร้อมชื่อ+รูปแฟน · ถ้าไม่ใช่แฟน แตะ **ไม่ใช่แฟน** ยกเลิกทันที (ใน 24 ชม.) |
| พิมพ์ `จับคู่` ระหว่างรอ | บอกสถานะ "รอแฟนอยู่ เหลือ X นาที" |
| แฟนยังไม่เคยกดยอมรับนโยบาย | กดยอมรับแล้วไปต่อได้เลย ไม่ต้องส่งรหัสใหม่ |
| `ของเรา` · `สรุปคู่` · `สรุปวันนี้` | การ์ด **💑 วันนี้ของเรา** ยอดรวมสองคน + เดือนนี้ของเรา (ไม่แยกว่าใครใช้เท่าไหร่) |
| แตะ **🔒** ตอนจด / หลังจด / ใน `แก้ไข` | รายการนั้นเป็นส่วนตัว แฟนไม่เห็น ไม่นับในยอดของเรา |
| `เลิกคู่` | ถามยืนยัน → เลิกฝ่ายเดียวได้ทันที บอทแจ้งอีกฝ่ายสั้นๆ ไม่บอกเหตุผล |
| `ยกเลิกรหัส` | รหัสเชิญที่ยังไม่ใช้ ใช้ไม่ได้ทันที |

- ไม่คัดลอกข้อมูล: รายการยังอยู่ใต้ `users/{uid}` ของเจ้าของ เซิร์ฟเวอร์รวมยอดให้ตอนขอดู · เลิกคู่ = ไม่มีอะไรต้องลบ
- **หน้าเว็บ:** จับคู่แล้วจะมีปุ่มสลับ `👤 ของฉัน | 💑 ของเรา` (คนโสดไม่เห็น) · การ์ดชมพู-ม่วง หมู 2 ตัว รูปโปรไฟล์คู่ · รายวัน/เดือน/ปีรวมกัน · รายการมีป้ายว่าใครจด (แก้ได้เฉพาะของตัวเอง) · สวิตช์ 🔒 ตอนเพิ่ม/แก้ · การ์ด "โหมดคู่รัก" ในตั้งค่า (เลิกคู่ / ชวนแฟน) · ทดลอง `/?demo=1&couple=1`
- API: `boot` คืน `couple {name, pic, since}` · `coupleEntries` · `coupleYear` · `unpair` — เซิร์ฟเวอร์หาคู่จากบัญชีตัวเองเท่านั้น ไม่รับ uid จากหน้าเว็บ และไม่ส่ง uid/รายการ 🔒 ออกไป
- ข้อมูล: `couples/{id}` (members, names) · `users/{uid}.coupleId` · `invites/{แฮชของรหัส}` · `entries.private` · `months.pinc/pexp` (ยอดส่วนตัว → ยอดของเรา = `inc - pinc`)
- กันเดารหัส: 31⁸ แบบ · 5 ครั้ง/ชม./คน · เก็บแค่แฮช · push ใช้แค่ตอนจับคู่/เลิกคู่
- ขอยินยอมเฉพาะคนที่จับคู่ (ไม่เพิ่ม `POLICY_VERSION`) · รายละเอียดใน `/privacy.html` ข้อ 15
- ลบข้อมูล / หมดเวลา 30 วัน → เลิกคู่อัตโนมัติ · หลังบ้านเห็นแค่ "มีคู่" ไม่เห็นว่าใครหรือยอดเท่าไหร่
- ตั้งค่าเพิ่มได้ (ไม่บังคับ): `LINE_OA_ID` (ค่าเริ่มต้น `@514ddese`) ใช้ทำลิงก์ส่งให้แฟน

## 👑 หลังบ้าน (เจ้าของระบบ)
1. พิมพ์ `ไอดีของฉัน` ในแชท → คัดลอกรหัสที่บอทตอบ
2. Vercel → Settings → Environment Variables → เพิ่ม `ADMIN_UID` = รหัสนั้น → Redeploy
3. พิมพ์ `หลังบ้าน` ในแชท → แตะ 📊 เปิดหลังบ้าน (หรือ `https://liff.line.me/<LIFF_ID>?page=admin`)
- เห็น: จำนวนคน/เพดาน, คิว, ใช้งานวันนี้/7 วัน, คนใหม่, รอกดยอมรับ, ใกล้ถูกลบ, รายชื่อ (ชื่อ + วันที่ใช้ **ไม่แสดงยอดเงิน**)
- ทำได้: ปรับจำนวนคน, ลบผู้ใช้ (แตะ 2 ครั้ง), เคลียร์คนหมดเวลา · ทดลองดู: `/?demo=1&page=admin`
- (ไม่บังคับ) ใส่ `CRON_SECRET` ใน Vercel → มีแค่ Vercel ที่เรียกลบอัตโนมัติได้

## 📸 อ่านสลิป (Google Gemini)
- ส่งรูปสลิปในแชท → AI อ่านยอด/ผู้รับ/วันที่ → แตะหมวด **1 ครั้ง** บันทึกเลย · ร้านเดิมบอทจำหมวดให้ (แยกต่อคน)
- **ไม่เก็บรูป** ดึงจาก LINE ไว้ในหน่วยความจำ ส่งให้ Gemini แล้วทิ้ง เก็บแค่ยอด ชื่อผู้รับ วันที่ และรหัสกันจดซ้ำ
- กันสแปม: คนละ 1 รูป / 3 วิ · กันโควต้าหมด: ทั้งระบบไม่เกิน `GEMINI_RPM` (ค่าเริ่ม 10) ครั้ง/นาที · เต็ม/อ่านไม่ออก → ปุ่ม ✍️ พิมพ์เอง / 🔢 กดตัวเลข (เปิดเว็บ `?add=1`)
- ตั้งค่า: Vercel → `GEMINI_API_KEY` (ไม่บังคับ: `GEMINI_MODEL`, `GEMINI_RPM`) · โค้ด `lib/slip.js`
- เพิ่มฟีเจอร์นี้แล้วนโยบายเป็นฉบับ 2 ทุกคนต้องกดยอมรับใหม่ 1 ครั้ง

## ⚡ ทำไมเร็ว
- บอท: อ่านข้อมูลที่ต้องใช้ทั้งหมด**ในรอบเดียว** (`prefetch` ใน `lib/store.js`) · งานไม่เร่งทำหลังตอบ (`later` ใน `lib/ctx.js`) · ขึ้น "…" ในแชททันที
- เว็บ: หลังยืนยันกับ LINE ครั้งแรก ระบบออก**บัตรผ่าน 12 ชม.** (เซ็นด้วย `LINE_CHANNEL_SECRET` ปลอมไม่ได้) ไม่ต้องถาม LINE ทุกครั้ง
- เว็บ: รายปีจำไว้ในเครื่อง โชว์ทันทีแล้วค่อยอัปเดต · โหลดรายปี + เดือนก่อนไว้ล่วงหน้า
- แนะนำเปิด **Fluid Compute** ใน Vercel (Settings → Functions) ลดเครื่องเย็น

## ⚙️ ติดตั้งครั้งแรก (ทำครั้งเดียว)

1. **Firebase**: สร้าง Firestore (ที่ตั้ง `asia-southeast1`) → Project settings → Service accounts → Generate new private key
2. **LINE Messaging API**: เอา Channel secret + Channel access token
3. **LINE Login + LIFF**: สร้าง LIFF (Size: Full, Endpoint: `https://<เว็บ>.vercel.app/`, Scopes: openid + profile) แล้วตั้ง channel เป็น **Published**
4. **Vercel → Environment Variables** ใส่ 5 ตัว แล้ว **Redeploy**

   | Name | ค่า |
   |---|---|
   | `LINE_CHANNEL_SECRET` | Channel secret |
   | `LINE_CHANNEL_ACCESS_TOKEN` | Channel access token |
   | `LINE_LOGIN_CHANNEL_ID` | Channel ID ของ LINE Login |
   | `LIFF_ID` | LIFF ID |
   | `FIREBASE_SERVICE_ACCOUNT` | เนื้อหาไฟล์ .json ทั้งไฟล์ |

5. **Webhook URL**: `https://<เว็บ>.vercel.app/api/webhook` → Verify → เปิด Use webhook
6. **Rich Menu** 3 ช่อง: เข้าสู่ระบบ = `https://liff.line.me/<LIFF_ID>` · ตั้งค่า = `...?page=settings` · สรุปวันนี้ = ข้อความ `สรุปวันนี้`

⚠️ ห้ามอัปไฟล์ .json ของ Firebase หรือรหัสใดๆ ขึ้น GitHub (repo นี้เปิดสาธารณะ)
